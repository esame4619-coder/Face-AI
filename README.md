# المحترف في AI — خادم المعالجة

خادم FastAPI لمحرك FaceFusion ومعالجة الصور. لا يستخدم API مدفوعاً.

## تشغيل محلياً
من مجلد المشروع:
```bash
docker build -t mohtarif-ai .
docker run --rm -p 8000:8000 -e PORT=8000 -e API_KEY="ضع-مفتاحاً-طويلاً-خاصاً-بك" mohtarif-ai
```
ثم أدخل في التطبيق: `http://عنوان-جهازك:8000`، وأدخل نفس مفتاح الوصول في إعدادات التطبيق.

## نشر مجاني على Hugging Face Spaces (CPU)
1. أنشئ Space جديداً من نوع **Docker** واختر **CPU Basic / Free** إن كان متاحاً لحسابك.
2. اربط هذا المستودع بالـSpace أو انقل محتوياته إليه؛ يجب أن يكون `Dockerfile` في جذر Space.
3. من Settings → Variables and secrets أضف Secret باسم `API_KEY` وضع قيمة عشوائية طويلة لا تشاركها.
4. انتظر انتهاء أول عملية بناء. أول تشغيل/طلب قد يستغرق وقتاً إضافياً لتنزيل نماذج FaceFusion.
5. انسخ رابط Space (مثل `https://اسمك-اسمspace.hf.space`) إلى خانة خادم المعالجة في التطبيق، وأدخل نفس قيمة `API_KEY` في خانة مفتاح الوصول، ثم احفظ واختبر الاتصال.

## حدود الخطة المجانية
- الخادم يعمل على CPU فقط؛ تبديل الوجوه قد يكون بطيئاً جداً وقد يتجاوز عدة دقائق.
- Spaces المجانية قد تتوقف عند عدم الاستخدام وتحتاج وقتاً للاستيقاظ.
- لا توجد GPU مجانية مضمونة، ولا نضمن استمرار توفر الخطة المجانية أو مواردها.
- لا ترفع صوراً خاصة أو حساسة إلى خادم عام. فعّل `API_KEY` كـSecret دائماً. رابط `/health` عام لقياس حالة الخادم، بينما واجهات المعالجة تتطلب المفتاح إذا تم ضبطه.

## نقاط API
- `GET /` حالة الخدمة.
- `GET /health` حالة المحرك.
- `POST /api/faceswap` ملفا `source` و`target`.
- `POST /api/enhance` ملف `image` (تحسين أساسي، وليس نموذج Super Resolution AI).
